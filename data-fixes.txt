# Corrections to the Divinum Officium data (repo/web/www/horas).
#
# They are kept here, outside repo/, so that no git pull, checkout or fresh
# download can lose them. `python datafixes.py` writes them into repo/ and the
# built app; build-exe.py (full and --quick) writes them into the app.
# `python datafixes.py --pull` updates repo/ from GitHub and keeps them.
#
# Each entry: "== FILE [Section]", notes ("why:", "source:"), "---", then the
# section's text, which replaces the file's own.

== Latin/Sancti/04-23.txt [Lectio94]
replaces: 704247eac0d2
why: the Latin file had the English lesson in place of the Latin (St George, ninth lesson)
source: Gueranger, The Liturgical Year, 23 April: the historical lesson approved for the dioceses of England; "fuisset." printed there made "fuisset,"
---
Georgius, inter orientales Martyres Magni nomine commendatus, in persecutione Diocletiani gloriosam pro Christo mortem subiit. Quum paulo post sub Constantino pax Ecclesiæ data fuisset, Martyris memoria celebrari cœpit, erectis sub ejus invocatione templis in Palæstina prope Liddam et Constantinopoli; deinceps autem in aliis partibus Orientis, et postea in Occidente celebris fuit erga illum fidelium devotio. Ab antiquis temporibus christiani exercitus contra hostes pugnaturi sanctos Georgium, Mauritium et Sebastianum patronos invocaverunt. Porro sanctum Georgium Martyrem jamdudum in Anglia specialiter cultum Benedictus decimus quartus Pontifex Maximus totius Regni Protectorem declaravit.
